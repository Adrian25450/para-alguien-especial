# Para alguien especial 🌷

Una carta web romántica, hecha con HTML, CSS y JavaScript. No necesita instalar dependencias: abre `index.html` en tu navegador.

La página incluye un jardín animado de rosas rojas en SVG, un diseño adaptable en tonos crema, rojo y vino, una galería local en `assets/recuerdos/` con seis fotos optimizadas para web, una línea de tiempo de recuerdos, un carrusel de fotos, mensajes interactivos sobre los momentos favoritos y el video oficial de «hasta que LLEGUE YO», que solo se carga cuando la visitante lo activa.

## Personalizar

- Edita el texto de la carta en `index.html`.
- Cambia el título y la firma si quieres hacerla más personal.
- Los estilos de las secciones y el fondo animado están en `extras.css`; las flores y la carta se personalizan en `style.css` y `script.js`.
